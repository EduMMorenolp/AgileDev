# Glosario: Sistema de Pedidos Online

| Termino | Definicion |
|---------|-----------|
| SKU | Identificador unico de producto en el catalogo |
| Carrito de compras | Conjunto de productos seleccionados por el cliente para comprar |
| Despacho | Proceso de preparacion y envio del pedido desde el deposito |
| JWT | JSON Web Token, mecanismo de autenticacion sin estado |
| MVP | Minimum Viable Product, version minima funcional del producto |
