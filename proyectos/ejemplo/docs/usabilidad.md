# Usabilidad y Accesibilidad: Sistema de Pedidos Online

## Perfil de usuarios
- Clientes corporativos (30-55 anos, experiencia tecnica basica-media)
- Operadores de deposito (25-50 anos, uso diario de sistemas internos)
- Administradores (35-60 anos, toman decisiones de compra)

## Requisitos de accesibilidad
- Cumplir con WCAG 2.1 nivel AA
- Soporte para lectores de pantalla (etiquetas ARIA en formularios)
- Contraste minimo 4.5:1 en textos
- Navegacion completa por teclado

## Nivel de usabilidad esperado
- Un usuario nuevo debe poder completar un pedido en menos de 5 minutos
- Maximo 3 clicks desde el inicio hasta confirmar pedido
- Curva de aprendizaje: operativo en la primera sesion

## Dispositivos objetivo
- Web desktop (Chrome, Firefox, Edge)
- Tablet (iPad, Android) para operadores en deposito
- Mobile responsive para consulta de precios

## Idiomas soportados
- Espanol (idioma principal)
- Ingles (interfaz administrativa)
