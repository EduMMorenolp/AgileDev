# Glosario: Sistema de gestion - Producto & Tecnología

| Termino | Definicion |
|---------|-----------|
| Solicitud interdepartamental | Petición formal realizada por un Director de otra área hacia la Mesa de Producto & Tecnología, tipificada y con trazabilidad. |
| Triage / Gobernanza | Proceso de evaluación y decisión (aprobación o rechazo) que realiza la Directora sobre cada solicitud entrante. |
| Instancia de trabajo | Proyecto o tarea formal creada a partir de una solicitud aprobada, con asignación de colaboradores, fecha de entrega y estado de avance. |
| RBAC | Role-Based Access Control — control de acceso basado en roles que restringe acciones según el perfil del usuario (Solicitante, Directora, Coordinador, Colaborador). |
| Mesa de Producto & Tecnología | Equipo interno multidisciplinario (UX, Frontend, Backend, QA, DevOps) responsable del desarrollo y mantenimiento de productos tecnológicos de la organización. |
